## 모임 중간 지점 찾기 — 화면 플로우

```mermaid
flowchart TD
  A[홈: 출발지 입력] -->|CTA 활성| B[조건 선택 시트]
  A -->|상태 유지| D[공유/딥링크 복원]
  B --> C{검색 실행}
  C -->|성공| E[결과: 지도 탭]
  C -->|성공| F[결과: 리스트 탭]
  C -->|빈 결과| G[반경 확대/카테고리 변경 제안]
  E --> H[장소 상세]
  F --> H
  H --> I[공유]
  D --> A
```

- 주요 전환: A → B → C → E/F
- 공정성 배지: 결과 카드/마커에 최장 이동자 기준 편차 표시
