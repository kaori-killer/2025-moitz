# 모바일 와이어프레임 v0.3 — 출발지 우선

조건을 먼저가 아니라, 출발지를 먼저 입력한 뒤 조건을 선택하는 플로우로 재구성했습니다.

---

## 1) 홈 — 출발지 입력

+---------------------------------------------------+
| 모잇지?                                           |
| 모임의 중간 지점을 빠르게 찾기                    |
+---------------------------------------------------+
| [ 역을 입력하세요… (예: 강남역, 홍대입구역)    ] |
|  최근/즐겨찾기  ● 현재 위치 추가                  |
|  선택됨: [강남역 ✕] [잠실역 ✕] [추가…]           |
|  조건 요약: (미선택)  ┃  [ 조건 선택 ]            |
+---------------------------------------------------+
| [ 중간 지점 찾기 (참여자 2) ]  (조건/출발지 충족 시 활성)
+---------------------------------------------------+

---

## 2) 조건 선택 시트(모달)

+---------------------- 바텀시트 --------------------+
| 조건 선택                                             |
| [o] 카페  [ ] 식당  [ ] 스터디 카페  [ ] 술집        |
| [ ] 액티비티  [ ] PC방/노래방  [ ] 엔터테인먼트      |
| 반경: 1km [-] 1.5km [+]   교통: 도보/대중교통       |
| [ 적용하기 ]                                         |
+-----------------------------------------------------+

---

## 3) 결과 — 지도 탭

+---------------------------------------------------+
| < 홈  결과                                          |
+---------------------------------------------------+
|  (지도)
|   ● 중앙지점                                        |
|   ◆ 후보장소1  ◆ 후보장소2                          |
|   ─ 반경 원 표시                                    |
+---------------------------------------------------+
| 필터: 거리·시간 | 정렬: 편차↓ | 보기: 지도/리스트   |
+---------------------------------------------------+

## 5) 장소 상세

+---------------------------------------------------+

+---------------------------------------------------+

| 소요시간: A 22분 / B 18분 / C 28분                 |
| [ 길찾기 ]  [ 공유 ]                                 |

---

## 6) 공유/초대(딥링크)

+---------------------------------------------------+
| 링크 공유                                           |
+---------------------------------------------------+
| 출발지: 강남역, 잠실역                              |
| 조건: 카페, 반경 1.5km                              |
| [ 링크 복사 ]  [ 카카오톡 공유 ]                     |
| 재방문 시 상태가 자동 복원됩니다.                   |
+---------------------------------------------------+

---

메모: CTA 활성 조건은 (출발지 ≥ 2) AND (카테고리 ≥ 1). 홈과 입력 화면 모두에서 조건 요약을 노출하고 즉시 변경 가능하도록 합니다.
